PROJECT 06 – NETWORK SERVICES

Purpose:
Practice configuring DHCP services and improving network availability using Windows Server 2022.

Servers:
- ZYWIN01 – Primary DHCP Server
- ZYWIN02 – Standby DHCP Server

Work Completed:
- Installed the DHCP Server role on both servers.
- Completed DHCP post-installation configuration.
- Created a DHCP scope named LAN.
- Configured the IP address range and exclusion range.
- Set the default gateway and 7-day lease duration.
- Configured DHCP failover between both servers.
- Selected Hot Standby mode and assigned ZYWIN02 as the standby server.
- Reviewed the completed configuration.

Key Takeaway:
Learned how DHCP assigns IP addresses to devices on a network and how failover helps keep DHCP services available if the primary server becomes unavailable.

Environment:
Windows Server 2022 virtual lab.
