Project 06 – Network Services & Business Continuity

Project Summary:
Configured DHCP services on two Windows Server 2022 virtual machines and created a DHCP failover relationship using Hot Standby mode.

Lab Environment:
- Primary Server: ZYWIN01
- Standby Server: ZYWIN02
- Operating System: Windows Server 2022
- Virtual Lab Environment

Tasks Completed:
1. Installed the DHCP Server role on both servers.
2. Created and configured a DHCP scope.
3. Configured the IP address range and exclusions.
4. Set the default gateway, lease duration, and domain name.
5. Configured DHCP failover using Hot Standby mode.
6. Reviewed the failover configuration.

Skills Practiced:
- Windows Server Administration
- DHCP Configuration
- IP Address Management
- Network Services
- DHCP Failover
- High Availability

Note:
This project was completed in a virtual lab for educational and portfolio purposes.
