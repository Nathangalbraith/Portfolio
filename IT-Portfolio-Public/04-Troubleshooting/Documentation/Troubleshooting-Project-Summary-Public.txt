Troubleshooting Project Summary

Project: IT Help Desk Troubleshooting

Project Overview:

This project involved practicing basic troubleshooting techniques using Windows Server and Windows 11.

Tasks Completed:

1. Network Connectivity Testing
Used ping commands to test communication between two Windows Server machines. Both machines successfully responded with 0% packet loss.

2. Windows System File Check
Used the SFC /scannow command to check Windows system files. The scan completed successfully and found no integrity violations.

Tools Used:

- Windows Server 2022
- Windows 11
- PowerShell
- Ping
- System File Checker (SFC)

Skills Practiced:

- Network connectivity testing
- Basic Windows troubleshooting
- PowerShell commands
- Checking Windows system file integrity
- Recording troubleshooting results

Project Outcome:

Successfully completed network connectivity tests and a Windows system file scan. Documented the results and practiced common troubleshooting techniques used by IT support technicians.
