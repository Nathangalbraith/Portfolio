Ticket Lifecycle Project Summary

Project: Northstar Technologies Help Desk

Project Overview:

This project involved creating and managing simulated IT Help Desk tickets using GitHub Issues. The goal was to practice handling common employee support requests from the initial report through troubleshooting and resolution.

Tickets Completed:

1. Account Lockout
Helped an employee regain access after their account became locked.

2. Internet Connectivity
Troubleshot a network connection and corrected an incorrect DNS configuration.

3. Microsoft Word Issue
Used Microsoft Office Quick Repair to resolve an application problem.

4. Password Reset
Verified an employee's identity and reset their account password.

Tools Used:

- GitHub Issues
- Active Directory
- Windows troubleshooting tools

Skills Practiced:

- Creating and managing support tickets
- Prioritizing support requests
- Troubleshooting common IT problems
- Documenting resolutions
- Closing completed tickets

Project Outcome:

Successfully created, documented, prioritized, and closed four simulated Help Desk tickets. This project provided practice with the ticket lifecycle and common entry-level IT support responsibilities.
