Network Connectivity Test

Objective:
Verify network connectivity between two Windows Server machines.

Environment:
- Server 1: Windows Server 2022 Datacenter
- Server 2: Windows Server 2022 Datacenter

Testing:
Used the ping command to test connectivity between both machines.

Server 1 to Server 2:
- 4 packets sent
- 4 packets received
- 0% packet loss

Server 2 to Server 1:
- 4 packets sent
- 4 packets received
- 0% packet loss

Result:
Both machines successfully responded to ping requests.
Network connectivity was confirmed in both directions.
