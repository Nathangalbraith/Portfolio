Identity Lifecycle Project Summary 

Project: Northstar Technologies - Identity Management

Project Overview:

This project involved creating and managing employee accounts and security groups using Active Directory in a Windows Server 2022 lab environment.

Tasks Completed:

1. Active Directory Setup
Installed Active Directory Domain Services and DNS and created the northstar.test domain.

2. Organizational Units
Created department organizational units for IT, Human Resources, Finance, and Sales.

3. Employee Account Management
Created employee accounts for John Smith, Sarah Johnson, Michael Davis, and Emily Wilson.

4. Security Group Management
Created department security groups and assigned employees to their appropriate groups.

Tools Used:

- Windows Server 2022
- Active Directory Users and Computers
- Active Directory Domain Services
- DNS
- PowerShell

Skills Practiced:

- Active Directory administration
- User account creation
- Organizational unit management
- Security group management
- Basic access control
- DNS configuration

Project Outcome:

Successfully built a basic Active Directory environment for a simulated company. Practiced managing employee accounts, organizing departments, and assigning group membership.
